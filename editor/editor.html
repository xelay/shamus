Room Editor (Shamus-like)

Left-click a cell to apply the selected tool. Every change is committed immediately and auto-saved to this browser's localStorage (a "draft") — so a page refresh or an accidentally closed tab won't lose your edits.

But this is not the same as saving into the game. The game only reads src/data/room-overrides.json from the file system. The browser draft is a temporary safety net while you edit. To actually get your edits into the game: click "Export overrides.json" (downloads a file), replace src/data/room-overrides.json in the project with it, and restart the game.

Every time it opens, the editor automatically picks up the already-committed room-overrides.json (if the server is serving it over the network) and layers this browser's draft on top — so previously saved edits are never lost, even if you only edit one new room in a session.
