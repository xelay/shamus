# Shamus-like — личный фан-клон (не для публикации)

Это **личный некоммерческий проект для собственного использования**, вдохновлённый
геймплеем игры *Shamus* (Synapse Software, 1982, автор — Cathryn Mataga). Здесь нет
ни одного ассета или байта кода из оригинала: вся графика — программные пиксель-спрайты,
весь звук — синтезированные Web Audio эффекты, все 128 комнат (4 уровня × 32 комнаты)
сгенерированы собственным процедурным алгоритмом. Проект не предназначен для публикации
или коммерческого использования.

## Как запустить

Это чистый статический сайт (vanilla JS + Canvas, без сборки), но браузеры не разрешают
ES-модулям (`<script type="module">`) грузиться напрямую с `file://` — нужен локальный
HTTP-сервер. Вариант, который сработает почти всегда:

```bash
node serve.js
```

(нужен только Node.js, никаких npm-пакетов; порт по умолчанию 8000, другой — `node serve.js 3000`).

Альтернативы, если Node не установлен:

```bash
# Node уже есть, но без своего сервера
npx http-server -p 8000

# Python. На Windows команда часто называется "python", а не "python3" —
# "python3" может перехватываться заглушкой Microsoft Store и выдавать
# "Python was not found". Если и "python" не находится — Python либо не
# установлен, либо отключён алиас в Settings > Apps > Advanced app settings
# > App execution aliases.
python -m http.server 8000
```

Либо в VS Code — расширение **Live Server**: правый клик на `index.html` →
«Open with Live Server», вообще без терминала.

Затем откройте `http://localhost:8000/`.

## Управление

- **WASD / стрелки** — движение
- **Space** — выстрел (можно держать в полёте до 2 зарядов одновременно, как в оригинале)
- **P** — пауза
- **N** — новая игра (в меню, стирает сохранение)
- **Enter** — подтвердить / продолжить сохранённую игру

Прогресс (уровень, комната, счёт, собранные ключи) автоматически сохраняется в
`localStorage` браузера — сервер для этого не нужен.

## Структура проекта

```
index.html            точка входа
src/
  main.js              бутстрап: канвас, игровой цикл, стейт-машина (меню/игра/пауза/game over)
  engine/               переиспользуемый "движок", не знает о Shamus-специфике
    loop.js             game loop с фиксированным таймстепом (60 Гц)
    input.js            клавиатура (isDown / wasPressed)
    collision.js         AABB/tile-коллизии
    audio.js             синтез звука (Web Audio, без сэмплов)
    save.js              localStorage save/load
    prng.js              детерминированный ГПСЧ (mulberry32) для процедурной генерации
  game/
    constants.js         все размеры/скорости/тайминги в одном месте
    sprites.js            программные пиксель-спрайты (без внешних PNG)
    levelgen.js           генератор 4×32 комнат: связность, дверь-ключ, враги
    room.js               рантайм одной комнаты (респаун врагов, таймер Тени)
    world.js               игровое состояние: уровень/комната/счёт/жизни/переходы
    hud.js / render.js     отрисовка HUD и сцены
    entities/              player, enemy, shadow, projectile, pickups (key/exit)
  data/
    room-overrides.json    ручные правки комнат поверх процедурной генерации (см. ниже)
editor/
  editor.html, editor.js   отдельный инструмент для ручного редактирования комнат
```

## Как устроена генерация уровней

Каждый уровень — это граф из 32 комнат (сетка 8×4), связность гарантирована
остовным деревом (плюс немного петель для разнообразия). Генерация детерминирована
(фиксированный сид) — при каждом запуске получается один и тот же персистентный мир,
как и в оригинале (в отличие от Berzerk, где комнаты рандомны).

Прогрессия "замок-ключ": на пути от стартовой комнаты к выходу выбирается ребро графа,
которое реально разделяет граф на две части (проверяется BFS — если после удаления ребра
выход всё ещё достижим окольным путём через петлю, оно не годится, ищется следующее).
Ключ кладётся в комнате, достижимой без пересечения этого ребра. Так гарантируется, что
без ключа выход физически недостижим. Изредка (если все ребра пути оказываются
"нежёсткими" из-за петель) уровень может остаться без замка — тогда он просто полностью
открыт, это безопасный fallback, не баг.

Тень появляется, если задержаться в комнате дольше `SHADOW_TIMEOUT` (см. constants.js);
её нельзя убить, только временно оглушить выстрелом.

## Редактор комнат

Откройте `editor/editor.html` через тот же локальный сервер
(`http://localhost:8000/editor/editor.html`). Выберите уровень и комнату, кликайте по
тайлам, чтобы менять их тип, расставляйте/убирайте врагов, отмечайте ключ/выход. Кнопка
«Экспортировать overrides.json» скачает файл — замените им
`src/data/room-overrides.json` и перезапустите игру: правки наложатся поверх
процедурной генерации именно для тех комнат, которые вы редактировали (остальные
127 комнат останутся процедурными).

## Известные упрощения и нюансы (сознательные, не баги)

- Все виды урона (враг, электростена) сейчас одинаково отнимают одну жизнь с коротким
  окном неуязвимости — в оригинале электростены убивали мгновенно и безусловно; это
  упрощение сделано намеренно, чтобы игра не была излишне карательной.
- Внутренние препятствия в комнатах расставляются процедурно с эвристикой "не блокировать
  центр" — теоретически (очень редко) может получиться неудобная комната; правится через
  редактор.
- Управление только с клавиатуры — тач/геймпад не реализованы (можно добавить позже).
- Никакой серверной части и облачных сохранений — только `localStorage` в конкретном
  браузере на конкретном устройстве.
- Музыка на титульном экране оригинала — общественное достояние («Marche funèbre d'une
  marionnette» Гуно), но здесь не воспроизводится вовсе: весь звук — процедурный синтез.

## Идеи для дальнейшего развития

- Touch-управление (виртуальный стик + кнопка) для мобильных.
- PWA-обёртка (service worker) для оффлайн-игры.
- Более сложные паттерны ИИ врагов.
- Полноценный уровень-редактор с undo/redo и предпросмотром связности комнат.
